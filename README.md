# WordPress Messages

WordPress üyelerinin birbirlerine özel mesaj göndermesini sağlayan, erişilebilirlik gözetilerek hazırlanmış bir eklenti.

## Kurulum ve kullanım

1. Eklenti klasörünü `wp-content/plugins/` dizinine yükleyin ve WordPress yönetim panelinden **WordPress Messages** eklentisini etkinleştirin.
2. **Ayarlar → WordPress Messages** sayfasından üyeler arasındaki mesajlaşmayı etkinleştirin veya devre dışı bırakın.
3. Bir WordPress sayfasına `[wordpress_messages]` kısa kodunu ekleyin.
4. Oturum açmış üyeler, alıcının kullanıcı adını yazarak mesaj gönderebilir ve gelen/gönderilen mesajlarını bu sayfada görüntüleyebilir.

Mesajlaşma yalnızca oturum açmış kullanıcılar için kullanılabilir. Mesaj formundaki alanlar etiketlidir; durum bildirimleri ve bölümler ekran okuyucu kullanıcılarına uygun semantik işaretlemeyle sunulur.
